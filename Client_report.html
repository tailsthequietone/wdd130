General Experience and Reflections

The most challenging part of this project was overcoming my own procrastination as well as waiting for the other people on my teams to overcome their own procrastination and get their parts done
I enjoyed making a nice wireframe. That's about it for me.
If I did this project again I would be more insistent about others getting things done as well as been more on top of getting things done myself.
I would feel more confident in working on a real-world project after this experience because now I know how to go about working with others better and now I know how to manage version control using Github.
